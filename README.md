## Features
- User & Admin roles
- Book indexing system
- ISBN scanner (camera-based)
- Manual payment verification

## Tech Stack
- PHP (WAMP)
- MySQL
- JavaScript

  ## How to Run

1. Clone this repository
2. Move project to your local server (htdocs for XAMPP/WAMP)
3. Import database to MySQL
4. Run via localhost

Note: ISBN scanner works for international books.

## About

This project was built as a final school project to explore system design, user roles, and API integration.

## Status
This project is still under development and open for improvements.
